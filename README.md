# Central Music - Musical Instruments e-commerce

A high-performance e-commerce web application for musical instruments build with **React** and **Tailwind CSS**. This project focuses on modern UI/UX, fast resource loading, and clean component architective.

## Feature
- **Modern UI:** Responsive design for catalog.
- **Performance Optimized:** Achieved 60+ Lighthouse score by implementing `fetchpriority`, preloading critical assets, and asset minification.
- **Dynamic Routing:** Seamless navigation using React Router.
- **Production Ready:** Fully deployed on Vercel with optimized production builds.

## Tech Stack
  - **Frontend:** React.js, Tailwind CSS
  - **Icons:** React Icons
  - **Bundler:** Vite
  - **Deployment:** Vercel
